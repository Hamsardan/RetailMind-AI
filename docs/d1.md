    # Day 1 — End-to-End ML Pipeline & ML-as-a-Service

## Objective

Establish RetailMind AI's initial machine learning backbone by developing an end-to-end customer churn prediction pipeline and exposing the persisted model through a reusable Python prediction service.

## Dataset

**Telco Customer Churn**

- Source: [Kaggle — Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
- Records: 7,043
- Original columns: 21
- Target variable: `Churn`

## Implementation

### 1. Data Ingestion and Exploration

Loaded the dataset using Pandas and inspected:

- Dataset dimensions and schema.
- Numerical and categorical features.
- Missing values and duplicate records.
- Target class distribution.

**Target distribution:**

| Class    | Records | Percentage |
| -------- | ------: | ---------: |
| No Churn |   5,174 |     73.46% |
| Churn    |   1,869 |     26.54% |

### 2. Data Cleaning

- Removed `customerID` because it is an identifier rather than a predictive feature.
- Converted `TotalCharges` to a numerical data type.
- Replaced 11 blank `TotalCharges` entries with 0, corresponding to customers with zero tenure.
- Encoded the target variable: `No = 0`, `Yes = 1`.

### 3. Train-Test Split

Used an 80:20 stratified train-test split.

- Training records: 5,634
- Testing records: 1,409
- Random state: 42

Stratification preserved the original target class distribution in both sets.

### 4. Feature Preprocessing

Implemented preprocessing using Scikit-learn's `ColumnTransformer`.

| Feature Type              | Transformation |
| ------------------------- | -------------- |
| Numerical (4 features)    | StandardScaler |
| Categorical (15 features) | OneHotEncoder  |

`handle_unknown="ignore"` was used in OneHotEncoder to handle previously unseen categories during prediction.

### 5. Model Training

**Baseline classifier:** Logistic Regression

The preprocessing operations and classifier were combined into one Scikit-learn Pipeline.

Configuration:

- `max_iter=1000`
- Training performed using the training split only.

### 6. Model Evaluation

The model was evaluated using the held-out test set.

**Baseline metrics:**

| Metric    | Result |
| --------- | -----: |
| Accuracy  | 80.55% |
| Precision | 65.72% |
| Recall    | 55.88% |
| ROC-AUC   | 84.21% |

**Confusion Matrix:**

|            | Predicted No | Predicted Yes |
| ---------- | -----------: | ------------: |
| Actual No  |          926 |           109 |
| Actual Yes |          165 |           209 |

The model achieved an ROC-AUC of 0.8421. Its recall of 55.88% indicates that further improvement in identifying customers who churn is a potential area of development.

### 7. Model Persistence

Persisted the complete fitted Scikit-learn Pipeline using Joblib.

**Artifact:** `models/churn_pipeline.joblib`

The saved artifact includes both the preprocessing transformations and the trained classifier.

The saved model was subsequently loaded and tested. Its predictions matched those of the original fitted pipeline.

### 8. Prediction Service

Implemented a reusable prediction helper in `src/predict.py`.

Supported inputs:

- Individual customer records represented as dictionaries.
- Multiple customer records represented as Pandas DataFrames.

Returned outputs:

- `churn_prediction`: Predicted churn class.
- `churn_probability`: Estimated probability of churn.

Both individual and batch prediction functionality were tested successfully.
